個人開発

LoveMap

PHP / JS

大阪の飲食店を地図と検索で探せるWebアプリです。店舗一覧、エリア検索、 詳細画面、地図表示、住所のジオコーディング、検索結果の並び替えを実装しています。 管理画面ではログイン、店舗の追加・編集・削除に対応しています。

  • クライアント: 検索画面、店舗詳細、地図表示
  • バックエンド: PHP API、店舗・エリア・評価データ
  • 管理画面: 店舗CRUDとコンテンツ管理

チーム開発・開発中

TheManTapTrip

React / Laravel / Docker

React Vite、Laravel、MySQL、Docker Composeで構成した旅行プラン提案アプリの モノレポです。nginx、client、backend、mysqlのサービス構成を持ち、バックエンドには Google認証、Sanctum、spot、question、choice、categoryのモデルがあります。 私はリーダー、GitHub管理、バックエンド、Docker部分を担当しました。

  • フロントエンド: welcome、home、detail、login、profile
  • バックエンド: Laravel API、認証、地点提案用のデータモデル
  • Docker: 複数サービスCompose、Nginxプロキシ、MySQL永続化
